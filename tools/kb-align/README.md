# KB-Align (geçici ad)

Kick–bas faz ve zaman hizalama plugin'i (VST3 / AU / CLAP), kick'e kilitli osiloskop ile.
Bas kanalına takılır, kick sidechain girişinden ölçülür; yalnız bası işler.

Şimdilik berkayeracademy reposunda `tools/kb-align/` altında duruyor (`tools/**` siteye yüklenmez).
İleride kendi reposuna taşınacak — karar kullanıcının.

| Dosya | İçerik |
|---|---|
| `docs/talimat.md` | Geliştirme talimatı (tek doğruluk kaynağı) |
| `docs/ilerleme.md` | Aşama aşama ilerleme, ölçümler, açık VARSAYIM'lar |
| `docs/arastirma/rakipler.md` | Aşama 1: rakipler, özellik tablosu, boşluklar |
| `docs/arastirma/dsp-yontemleri.md` | Aşama 1: DSP yöntemleri |
